# Notes

A clean, modern note-taking app built with React 19, shadcn/ui, and Tailwind CSS.

> Live: [eghesmati.github.io/Notes](https://EGhesmati.github.io/Notes)

---

**Tech:** React 19 · TypeScript 6 · Vite 8 · shadcn/ui · Tailwind CSS v4 · Lucide

**Features:** add / delete / search notes · dark & light theme · responsive grid · glassmorphism · lazy loaded components · debounced search
