# 📝 React Notes App

A simple Notes App built with **React**, **TypeScript**, **Vite**, and **shadcn/ui** to practice modern React development, state management, controlled components, and derived state.

## 🌐 Live Demo

🔗 **https://eghesmati.github.io/Notes/**

## ✨ Features

- ➕ Add notes
- 🗑️ Delete notes
- 🔍 Search notes
- 🔤 Live character counter
- 📊 Total notes counter
- ✅ Prevent empty notes
- 🎨 Modern UI with shadcn/ui
- ⚛️ Built with React Hooks (`useState`)
- 📘 Written in TypeScript

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- shadcn/ui
- CSS

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/eghesmati/Notes.git
```

Go to the project folder:

```bash
cd Notes
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
